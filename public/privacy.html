Randomander privacy notice

Draft updated 11 August 2026; owner approval is required before 1.0.

Who controls the app

Randomander is maintained by the owner of the Randomander GitHub repository. Use the repository support or security process to make a privacy request.

Data stored in your browser

Randomander stores settings, recent History, Saved pulls, and a disposable response cache in Web Storage on this device. This data is not synced to a Randomander account or application server. It remains until you clear it, the app evicts bounded cache/history data, or the browser removes site storage. History, Saved, cache, and clear-all controls are available in the app.

External requests

New draws request card data from Scryfall, and displaying card art or mana symbols can request Scryfall-hosted assets. The public build does not make automated requests for EDHREC deck counts or themes. Opening Scryfall, EDHREC, or marketplace links sends you to the service you selected, which applies its own privacy policy. Requests can disclose ordinary network information such as IP address, browser headers, the requested URL, and request time to those services.

Service attribution and fan content

Scryfall supplies card data, images, price snapshots, and allowlisted marketplace destinations. Randomander is not produced by or endorsed by Scryfall, does not process purchases, and has no stated affiliate relationship with those marketplaces. EDHREC is an independent outbound inspiration destination in the public build.

Randomander is unofficial fan content permitted under Wizards of the Coast's Fan Content Policy. Wizards does not approve or endorse it. Some materials are property of Wizards of the Coast LLC. © Wizards of the Coast LLC.

Analytics

Analytics are disabled for the 1.0 release. The production content policy and build checks reject analytics endpoints, so a build setting alone cannot enable them. Any future analytics change requires an owner-approved privacy decision, an updated notice, and reviewed changes to the app, content policy, build policy, and release evidence. Randomander does not send card History, Saved pulls, or filter values to an analytics service.

Fonts, cookies, retention, and choices

Randomander uses system fonts and does not request Google Fonts. The app does not set its own cookies. Local browser data follows the retention described above. The 1.0 build does not load an analytics service.

Changes

Material changes will update the effective date and release notes. This notice is a technical description and must be reviewed by the project owner for the jurisdictions where 1.0 is offered.

Randomander privacy notice

Effective 3 August 2026

Who controls the app

Randomander is maintained by the owner of the Randomander GitHub repository. Use the repository support or security process to make a privacy request.

Data stored in your browser

Randomander stores settings, recent History, Saved pulls, and a disposable response cache in Web Storage on this device. This data is not synced to a Randomander account or application server. It remains until you clear it, the app evicts bounded cache/history data, or the browser removes site storage. History, Saved, and cache controls are available in the app.

External requests

New draws request card data and images from Scryfall. Optional deck counts and themes request data from EDHREC. Opening price or inspiration links sends you to the selected external service, which applies its own privacy policy. Requests can disclose ordinary network information such as IP address, browser headers, requested card or metadata URL, and request time to those services.

Analytics

Production analytics are disabled by default. A deployment can explicitly enable Vercel Web Analytics with the VITE_ENABLE_ANALYTICS=true build setting. When enabled, Vercel describes the service as cookieless and anonymized and may process page/referrer, approximate location, browser/OS, device, and timing information. Randomander does not intentionally send card History, Saved pulls, or filter values as analytics events. Randomander does not initialize analytics when the browser sends Do Not Track or Global Privacy Control.

Fonts, cookies, retention, and choices

Randomander uses system fonts and does not request Google Fonts. The app does not set its own cookies. Local browser data follows the retention described above. Analytics retention, when enabled, is controlled in the deployment's Vercel account. You can block optional analytics with browser controls or use a deployment where it is disabled.

Changes

Material changes will update the effective date and release notes. This notice is a technical description and must be reviewed by the project owner for the jurisdictions where 1.0 is offered.
